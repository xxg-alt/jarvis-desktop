# 语音切换入口设计

## 目标

在贾维斯主面板输入框上方增加音色切换入口，避免用户手动编辑 `config.json`。

## 界面与交互

- 新增一栏“声音”标签和下拉框。
- 下拉框按 `edge_speech.PRESET_VOICES` 提供云希、云扬、云健、晓晓、晓伊。
- 初始值读取 `jarvis.CONFIG["tts_voice"]`，未配置时显示云希。
- 用户选择后立即更新 `jarvis.CONFIG["tts_voice"]`，后续语音使用新音色，不重启程序。
- 选择后同步保存到 `config.json` 的 `tts_voice` 字段，其他配置保持不变。

## 实现范围

仅修改 `jarvis_gui.py`：导入 `ttk`，创建下拉框及选择回调，在回调中更新运行配置并保存 JSON。复用现有 `jarvis.CONFIG` 和 `edge_speech.PRESET_VOICES`，不修改语音合成模块。

## 异常处理

保存失败时捕获异常并打印到现有界面记录区，保留当前运行选择，不让界面退出。读取配置沿用现有启动逻辑。

## 验证

- 对修改后的 Python 文件执行语法检查。
- 验证每个选项都会更新运行配置，保存后 `tts_voice` 与选择一致，其他配置不变。
- 模拟不可写配置路径，确认异常被记录且回调不向外抛出。
