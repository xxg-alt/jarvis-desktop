# 贾维斯 Windows 安装包设计

## 目标

把现有 Python/Tkinter 应用交付为 Windows 安装包。用户安装后从桌面或开始菜单启动“贾维斯”，不再运行 VBS/BAT，也不要求目标电脑安装 Python。

## 打包架构

- 使用 PyInstaller 将 `jarvis_gui.py` 及其 Python 依赖构建为无控制台窗口的 `Jarvis.exe`，采用 onedir 布局以兼顾启动速度和依赖兼容性。
- 随应用包含默认 `config.json` 和 `custom_voices` 资源，不包含 `.venv`、日志、缓存、`.env` 或任何 API 密钥。
- 保留现有启动画面、语音面板、系统托盘、热键、音色切换及语音合成功能，不重写业务模块。

## 安装与启动

- 使用 Inno Setup 生成中文界面的 `贾维斯安装包.exe`。
- 默认安装到当前用户的 `{localappdata}\Programs\Jarvis`，无需管理员权限。
- 创建桌面快捷方式、开始菜单项和卸载程序；快捷方式直接启动 `Jarvis.exe`。
- 配置和日志继续由现有代码写入应用目录；每用户安装位置可写，音色选择可在重启后保留。

## 构建与异常处理

- 增加可重复执行的 PyInstaller 配置和 Inno Setup 配置，构建失败时保留明确错误输出。
- 缺少构建工具时先安装 PyInstaller 和 Inno Setup，再执行构建；不修改应用功能来绕过打包错误。
- 安装包不包含本机个人密钥；语音识别和 Edge TTS 的联网要求保持不变。

## 验证

- 检查 Python 源码语法及打包配置。
- 完成 PyInstaller 构建，确认可执行文件及依赖齐全。
- 对打包后的程序做启动冒烟测试，确认进程能够运行且没有立即崩溃。
- 编译 Inno Setup 安装包，确认安装包存在且包含桌面、开始菜单和卸载配置。
- 不在未另行确认的情况下执行系统级安装或修改其他机器。
