# 「每次都要重填 API Key」问题分析与修复说明

日期：2026-11-18
涉及程序：`jarvis-desktop-v1.2\jarvis-desktop-v1`
改动备份：`_backup\apikey-fix-before-20261118-2145\`

---

## 一、先说结论：不需要数据库

原始诉求是"能不能给个数据库保存一下"。查证后结论是 **不加数据库**，因为：

1. **持久化本来没坏**——`%APPDATA%\Jarvis\config.json` 里确实躺着那把 Key（`sk-8697…3a2f`），说明保存过一次是成功的。
2. 真正的病因是 **"保存"这一步在用空值把已存的 Key 覆盖掉**。换成 SQLite 一样会被覆盖，只是换个文件丢。

数据库只能改善"存到哪"，解决不了"存了却看不见、不敢确定、只好再填一遍"这一层。

## 二、底层需求拆三层

| 层级 | 需求 | 数据库能解决吗 |
|---|---|---|
| 表层 | 少一次粘贴动作 | 不能 |
| 中层 | 配置一次长期有效，重启重装都不丢 | 部分（介质层面） |
| 底层 | **我能确认它现在是生效的** | 完全不能 |

底层才是真需求：界面为了安全不回填明文 → 打开面板是空的 → 你无法判断到底存没存 → 于是再粘一遍。

## 三、根因（代码级证据）

### 缺陷 1：空 Key 覆盖已保存的 Key

**全屏 HUD**（`web_fullscreen.py` `_apply_config`）
```python
if "api_key" in patch:
    key = str(patch["api_key"] or "").strip()
    clean["api_key"] = key       # ← 空串也照写
```

**Tk 经典界面**（`jarvis_gui.py` `_save_api_key`）
```python
jarvis.CONFIG["api_key"] = new_key       # ← 在 if new_key: 判断之外
self._save_config("api_key", new_key)    # ← 空串也写内存 + 写盘
```

触发链路：打开配置面板 → 密钥框本来就是空的（安全设计不回填）→ 顺手改个音色/模型 → 点保存 → **空串把已存好的 Key 一起写掉** → 下次进来又得重粘。

### 缺陷 2：三把 Key 混用，Key 与服务商错配

- `%APPDATA%\Jarvis\config.json`：`sk-8697…3a2f`（DeepSeek）
- 项目 `config.json`：`sk-6489…af9f`（DeepSeek）
- 桌面 `新建 文本文档.txt`：`sk-ws-…gmmg` + `https://maas.qianwenaiapi.com/compatible-mode/v1`

日志里那条 401 的正是 `…gmmg`——**第三方兼容网关的 Key 被填进了 DeepSeek 服务商**，必然 401。表现上是"AI 不回答"，很容易被误判成"Key 没存住"。

### 缺陷 3：保存时不做任何校验

存完就完事，对不对要等下次 401 才发现。

### 缺陷 4：配置双份明文

项目目录一份、APPDATA 一份、桌面 txt 三把。重装或打包会带走项目那份，两边打架时无法判断哪份生效。

## 四、本次改动

| # | 改动 | 位置 |
|---|---|---|
| 1 | **空值不再覆盖**：key 为空直接跳过写入，并返回"已保留原有配置"提示 | `web_fullscreen.py` `_apply_config`；`jarvis_gui.py` `_save_api_key` |
| 2 | **单一配置源**：程序自带 `config.json` 移除 `api_key`，明文只留 APPDATA 一份 | 项目 `config.json` |
| 3 | **保存即校验**：新增 `probe_api_key()`，用这把 Key 发一次 `max_tokens=1` 的探针请求；401/403 明确回报"不属于该服务商或已失效"。校验在后台线程跑，不阻塞保存 | `llm_brain.py` 新增；`web_fullscreen.py` 新增 `_verify_key_async` |
| 4 | **Key 指纹显示**：界面显示 `已保存 sk-869…3a2f · 留空保持不变`，明文仍不下发 DOM | `llm_brain.py` 新增 `key_hint()`；`web_fullscreen.py` `_read_config`；`web_fullscreen_ui/index.html` `applyConfig` |

## 六、现在的行为（你实际会看到的）

1. 打开配置面板，密钥框提示 **`已保存 sk-869…3a2f · 留空保持不变`** —— 一眼知道存的是哪把、给谁用。
