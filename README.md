# 贾维斯 v1 · Windows 桌面语音助手

喊一声“贾维斯”，就能让它打开软件、搜东西、调音量、截图、锁屏……

## 在电脑上安装（约 5 分钟，只做一次）

1. 把 `jarvis-desktop-v1.zip` 解压到一个固定文件夹，比如 `D:\Jarvis`，别放在临时目录
2. 确认电脑装了 **Python 3.11 或 3.12（64 位）**。没装就去 python.org 下载，安装第一页务必勾 **Add python.exe to PATH**
3. 双击 **`install.bat`**，等它装完（第一次要联网下载依赖）
4. 启动有两种方式：
   - **无黑窗口版（推荐）：** 双击 **`Jarvis.vbs`**，桌面上会出现一个悬浮小面板，没有终端黑窗口。点面板上的“隐藏到托盘”后，去任务栏右下角找蓝色 J 图标，双击能再打开面板，右键能退出
   - **终端版（调试用）：** 双击 **`start.bat`**，贾维斯在黑窗口里运行，出错时红字看得最清楚

面板上能看到它听到了什么、回复了什么，也能在输入框里打字下指令。

麦克风被 Windows 拦住时：设置 → 隐私和安全性 → 麦克风 → 打开“麦克风访问”和“允许桌面应用访问”。

> 仓库里的 `config.json` 是本地运行时配置，可能含 API Key，所以没有上传；首次使用请把 `config.example.json` 复制为 `config.json`，再按需填写。

## 怎么用

- **语音唤醒：** 直接说「贾维斯，打开记事本」；或者先说「贾维斯」，听它回“我在”，再说指令
- **热键：** 按 `Ctrl+Alt+J`，听它回“我在”后说话
- **文字兜底：** 麦克风不好用时，双击 `start-text.bat`，打字输入指令一样能控制

## v1 已经会做的事（直接说就行）

| 说法示例 | 效果 |
|---|---|
| 打开记事本 / 计算器 / 画图 / 浏览器 / 微信 / Word / Excel | 打开软件 |
| 关闭微信 | 关闭软件（会先问你确认） |
| 打开B站 / 打开知乎 | 打开网站 |
| 搜索明天天气 / 百度一下周杰伦 | 打开浏览器搜索 |
| 打开桌面 / 打开下载文件夹 | 打开文件夹 |
| 打开《某个文件名》 | 在桌面、文档、下载里找文件并打开 |
| 音量调大 / 调小 / 调到50 / 静音 | 调音量 |
| 亮度调到70 | 调屏幕亮度（部分台式显示器不支持） |
| 截图 | 截图存到 图片\贾维斯截图 |
| 输入你好世界 | 3 秒后把文字粘贴到你点好的输入框 |
| 按回车 / 点击 / 双击 | 模拟按键、鼠标 |
| 现在几点 | 报时 |
| 锁屏 | 锁定电脑 |
| 关机 / 重启 | 先确认，60 秒后执行；说“取消关机”可反悔 |

规则不认识的指令：如果你填了 Gemini 密钥（见下），它会交给 Gemini 理解成白名单里的动作；没填密钥时，它会老实说没学会，不会乱动。

## 让它更聪明（可选，免费）

1. 在电脑浏览器打开 aistudio.google.com/apikey，用复制图标复制一个完整的 Gemini 密钥
2. 把文件夹里的 `.env.example` 改名为 `.env`，把密钥粘进去保存
3. 重新启动贾维斯

注意：语音识别 v1 用的是谷歌的在线识别服务，需要联网，个别网络环境下可能不稳定；识别和 Gemini 都走你自己的网络和账号。密钥只存在你电脑的 `.env` 里，不要发到聊天里。

## 加你自己的软件

打开 `config.json`，在 `apps` 里加一行，比如 `"剪映": "JianyingPro.exe"`，之后说“打开剪映”就行。软件的 exe 名可以在任务管理器里右键该软件 → 打开文件所在位置看到。

## 安全说明

- 关机、重启、关软件这类动作，必须你二次确认才执行
- Gemini 只能返回白名单动作，返回别的会被丢弃
- 程序全部在本机运行，代码就这一个 `jarvis.py`，可以随便打开看

## 已知边界（v1 实话）

- 唤醒靠在线语音识别短句轮询，不是专业离线唤醒芯片，安静环境效果最好；吵的时候用热键或文字模式
- 它还不会“看着屏幕自己找按钮点”——那是 v2 要加的截图+看图理解，需要再接 Gemini 看图
- 我在云端没法替你在你的 Windows 上实测，第一次运行如果报错，把 start.bat 窗口里的红字截图发回来，我按报错改
